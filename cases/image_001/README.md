# 图片转录回归用例 image_001

该用例来自用户提供的三端可调稳压器内部电路图片转录，用于测试电路重建、原理图读取、连续连线显示和 AI 分区讲解。

包含 52 个器件：12 PNP、11 NPN、1 N 沟道 JFET、3 稳压二极管、23 电阻、2 电容；35 个网络，端口为 Vin、Vout、Adjust。

- `circuit.json`：转录参数、拓扑和假设。
- `symbol-evidence.json`：布线回归所需的端子名称与位置，不包含原生库符号绘图。
- `analysis.json`、`analysis.md`：基于实际连接生成的示例讲解。
- `connectivity.netlist.txt`：结构核对记录，不是已配置模型的可运行仿真平台。

原始图片带有第三方来源标记，本次发布不重新分发；原生几何回读、Cadence 绘图和本机截图也不附带。需要图形/实机验证时，在具有相应授权的 Cadence 环境中执行 `python build_image_case.py`，从当地 analogLib 重新读取端子并创建独立测试单元。脚本不会覆盖拓扑或显式参数不同的同名目标。

原始验证：所有端子与显式参数回读一致，35 个网络各有一个连续的物理连通分量，Cadence 检查 0 错误、0 警告。生成程序既验证电气网络，也检查导线实际连续，防止同名标签掩盖视觉断线。

关键假设：Vout 是浮动内部参考端而非地；感测电阻按原图保留 2.5 Ω；C2 返回 50 Ω 调整电阻之前的 N19。相近参考为 [onsemi LM317M 数据手册 Figure 2](https://www.onsemi.com/pdf/datasheet/lm317m-d.pdf)，其数值存在差异，不能据此断定图片的确切料号。

半导体模型、发射极面积比、外部分压和负载未知；未运行仿真，不给出精度、温漂、输出能力或保护阈值保证。
